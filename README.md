# AulaHelpIA

Aplicación móvil educativa para estudiantes de secundaria. Integra organización de tareas, horario inteligente y un tutor básico de inteligencia artificial para Matemáticas.

## Tecnologías utilizadas

- **Lenguaje:** Kotlin
- **Entorno:** Android Studio
- **Base de datos local:** SQLite (Room)
- **IA:** Gemini API
- **Control de versiones:** GitHub
- **Diseño:** Material Design

## Estado del proyecto

Actualmente en fase de desarrollo (MVP funcional). La app cuenta con:
- Gestión de tareas (crear, editar, completar)
- Horario semanal con recordatorios
- Tutor IA para Matemáticas (Gemini API)


## Instalación

Para probar la aplicación:
1. Clona el repositorio
2. Abre el proyecto en Android Studio
3. Compila y ejecuta en un dispositivo Android (versión 8.0 o superior)
